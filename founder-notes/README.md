# founder-notes — 羽島の思考ログ

代表・羽島の生の思考・仮説・観察をそのまま保存するフォルダ。
CLAUDE.md や SKILL.md のような「指示書」ではなく、「考えている途中のもの」を残す場所。

---

## 使い方

- 思いついたメモ・議論の整理・インプットの校閲結果などをここに保存する
- Claude に「founder-notes を見て」と言えば参照できる
- 投資家向け資料・SKILL.md の改訂時に「なぜそう設計したか」の根拠としても使える

## ファイル命名規則

```
YYYYMMDD_テーマ.md
```

例：`20260404_AIキャリア採用の未来.md`
